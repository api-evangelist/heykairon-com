Kairon provides an outbound prospecting tool for B2B teams, leveraging Claude AI to automate LinkedIn and email outreach. The platform identifies target contacts, scores them against ideal customer profiles, and runs personalized sequences from the operator’s own accounts. It offers a web interface, pricing plans, and integrates with CRM data, aiming to increase sales efficiency and lead generation for fintech, proptech, SaaS, and education companies.

**Areas:** B2B · Sales · AI · Outreach · Automation · Marketing

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Kairon: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
